**Shutter Motor (ESPHome)**

Проект управления рулонной шторой на базе **ESP32-C3 Super Mini** и драйвера шагового двигателя **TMC2209 v3.0**.

Контроллер реализован в ESPHome (`shutter_motor_esphome.yaml`) и предоставляет управление через сущность `cover` (Home Assistant API), а также сервисные кнопки для хоуминга и калибровки.

## Что делает проект

- Управляет шаговым двигателем **NEMA17** для открытия/закрытия шторы.
- Поддерживает позиционирование (0…100%) после калибровки времени полного хода.
- Делает безопасный старт: после загрузки отключает драйвер и выдерживает паузу.
- Поддерживает хоуминг в верхнюю точку по концевому выключателю.
- Поддерживает перекалибровку тройным нажатием концевика.
- Экспортирует кнопки управления (Home, Recalibrate, Jog Open, Jog Close).
- Дополнительно читает температуру/влажность с SHT3x по I2C.

## Подключение пинов (по `shutter_motor_esphome.yaml`)

> Ниже — фактические пины из YAML-конфига репозитория.

### ESP32-C3 → TMC2209

| Назначение | Пин ESP32-C3 | Куда на TMC2209 | Примечание |
|---|---|---|---|
| STEP | `GPIO2` | `STEP` | Импульсы шага |
| DIR | `GPIO5` | `DIR` | Направление вращения |
| EN | `GPIO4` | `EN` | Активный LOW (HIGH = драйвер отключен) |
| UART TX | `GPIO20` | `PDN/UART` (RX драйвера) | UART зарезервирован в конфиге |
| UART RX | `GPIO21` | `PDN/UART` (TX драйвера)<br>или через однопроводную схему | UART инициализирован, параметры драйвера по UART сейчас не настраиваются |
| DIAG | `GPIO10` | `DIAG` | В YAML отмечен как сохранённый/резерв |

### Прочие подключения

| Назначение | Пин ESP32-C3 | Примечание |
|---|---|---|
| Концевик верхней точки | `GPIO3` | Вход с подтяжкой `pullup: true` |
| I2C SDA (SHT3x) | `GPIO8` | Датчик `0x44` |
| I2C SCL (SHT3x) | `GPIO9` | Датчик `0x44` |

## Питание и силовая часть

- **LM2596** используйте для получения нужного напряжения питания (обычно 5 В для ESP32, отдельная линия для логики при необходимости).
- **TMC2209 + NEMA17** обычно питаются от отдельной линии мотора (например, 12/24 В).
- Обязательно объедините земли: **GND ESP32 = GND TMC2209 = GND питания**.
- Перед первым запуском настройте ограничение тока на TMC2209 (Vref/uart-настройки в зависимости от вашей платы и схемы).
- В моём случае ток драйвера настроен практическим способом: по температуре TMC2209 под нагрузкой («пальцем»), чтобы драйвер не перегревался и не терял шаги.

## Логика работы

1. После старта устройство отключает драйвер (`EN=HIGH`) и ждёт 10 секунд.
2. Если концевик верхней точки уже нажат на старте — позиция принимается как 100%.
3. Если не калибровано:
   - Команда `Open` запускает хоуминг в верхнюю точку.
   - Для полноценного позиционирования выполните перекалибровку.
4. Перекалибровка:
   - Тройной клик по верхнему концевику запускает режим перекалибровки.
   - Первое нажатие в режиме калибровки запускает движение на закрытие.
   - Второе нажатие фиксирует полное время хода, позиция становится 0%.

## Прошивка

1. Установите ESPHome.
2. Заполните Wi‑Fi секреты (`wifi_ssid`, `wifi_password`) в `secrets.yaml`.
3. Прошейте устройство:

```bash
esphome run shutter_motor_esphome.yaml
```

4. Добавьте устройство в Home Assistant через ESPHome API.

## Полезные замечания

- В проекте используется `board: esp32-c3-devkitm-1`.
- `api.reboot_timeout: 0s` — устройство не перезагружается при потере API-соединения.
- Если направление открытия/закрытия перепутано, поменяйте логику `dir_pin` или переставьте фазы мотора.
- Если логика концевика обратная (нажатие читается как OFF), измените `top_limit_inverted`.
